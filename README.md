# Ahmed G. Rahma: academic website

Built on the [Academic Pages](https://github.com/academicpages/academicpages.github.io) Jekyll template, with the content of the CV already filled in.

## Publish it on GitHub Pages (free)

1. Create a GitHub account if you do not have one.
2. Create a new public repository named `<your-username>.github.io`.
3. Upload every file in this folder to that repository (or push it with git).
4. `_config.yml` is already set for AhmedRahma96.
5. In the repository, go to Settings, then Pages, and set the source to the main branch. The site appears at `https://<your-username>.github.io` after a minute or two.

## Where things live

| To change | Edit |
|---|---|
| Sidebar (name, bio, ORCID, LinkedIn, ResearchGate, Scholar, email), site title | `_config.yml` |
| Top menu | `_data/navigation.yml` |
| Home page text | `_pages/about.md` |
| CV | `_pages/cv.md` |
| Publications | one file per paper in `_publications/` |
| Talks | one file per talk in `_talks/` |
| Projects | one file per project in `_portfolio/` |
| Teaching | one file per course in `_teaching/` |
| Partners page and map | `_pages/partners.md`, `images/partner-map.svg` |
| Photo | `images/profile.png` |
| CV as a PDF | upload it as `files/Ahmed_Rahma_CV.pdf` and a download link appears on the CV page |

Publications within a year are ordered by the day number in their `date` field (a later day is listed first).

Left out on purpose: references and the phone number from the CV.
